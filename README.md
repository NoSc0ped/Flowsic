# Flowsic

A reactive music player with visualizers that move with your music.

Flowsic plays your local audio files and draws live visuals that respond to the sound, and eventually to your mouse or touch too. It's built with web technology, so the same app can run on Windows and mobile.

## Status
Litteratly a plain project

## Planned features

- Play local audio files (MP3, WAV, etc.)
- Reactive visualizers driven by bass, mids, and treble
- Interactive visuals that respond to mouse and touch
- Playlist and player controls (play, pause, seek, volume)
- Windows app and mobile app versions (in the distant future)

## Built with

- JavaScript
- [Vite](https://vite.dev/) for the dev server and build
- Web Audio API for analyzing the music
- Canvas API for drawing the visuals

## Getting started

You need [Node.js](https://nodejs.org/) installed.

```
npm install
npm run dev
```

Then open the local address shown in the terminal, choose an audio file, and press play.
